# External IoT-Based Predictive Thermal Stress Monitoring System for EV Batteries

## Overview
This project is an IoT-based predictive thermal monitoring system designed to improve EV battery safety using external temperature sensing and Thermal Stress Index (TSI) prediction.

The system continuously monitors battery surface temperature and predicts overheating risk using rate-of-temperature-rise analysis.

---

## Features
- Real-time battery temperature monitoring
- Thermal Stress Index (TSI) calculation
- Predictive overheating detection
- LED and buzzer alerts
- LCD display status
- Cloud monitoring using ThingSpeak
- Offline-first safety operation

---

## Technologies Used
- Python

---

## Hardware Components
- Raspberry Pi 4
- DS18B20 Temperature Sensor
- LEDs
- Buzzer
- LCD Display

---

## System Workflow
1. Read temperature from sensor
2. Calculate temperature rise rate
3. Compute TSI
4. Trigger alerts
5. Upload data to cloud

---

## Performance Metrics
- Response Time: 180ms
- Processing Speed: 1.2 Hz
- Low false-positive rate
- Reliable real-time alerts
